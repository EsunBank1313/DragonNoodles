# 🚀 智慧 POS 收銀與雲端財務記帳系統 (Smart POS & ERP System)

一套為實體門市（餐飲小吃、連鎖麵線、生鮮零售）量身打造的 **全功能現代化智慧 POS 收銀、線上點餐與雲端財務記帳系統**。

---

## 🌟 核心特色與亮點功能

### 🧩 1. 全系統功能模組
* **🍽️ 桌號與內外帶管理**：內用掃碼/現場外帶一鍵切換、桌號鎖定、翻桌率分析。
* **🍜 多重規格自訂與加料專區**：多組規格獨立勾選（大小碗、麵條種類、辣度）、配料加價（大腸/肉羹/花枝羹/皮蛋/蚵仔）、套餐升級。
* **⚡ POS 現場快速結單**：櫃檯點餐送單即結單完成，免去待取餐等繁雜切換。
* **📱 顧客線上掃碼點餐 ＆ 即時取餐通知**：顧客手機免裝 App 掃碼即點；POS 點擊【✔ 完成】即時透過 WebSocket 推播至顧客手機跳出取餐通知與提示音。
* **📷 手機照片極速上傳**：後台商品支援手機相簿與相機拍照，秒級自動壓縮至 <80KB，手機操作超流暢。
* **💰 每日現金盤點計算機**：抽屜零錢備用金扣除、面額點鈔計算機、與系統即時營業額 100% 同步核算短溢差額。
* **📦 倉儲庫存與進貨日誌**：食材原料自動扣庫、安全庫存警報、進貨未付款狀態預設與完整異動歷程日誌。
* **🖨️ 智能廚房出單與列印**：支援 58mm/80mm 熱感小票、廚房製作工單、日結單 (Z-Report)、語音播報。
* **📊 進階財務損益與月報表**：總營收、平日/假日對比、單品銷量排行榜、固定成本結算、CSV 匯出。
* **🏆 供應商進貨與星級評鑑**：多廠商進貨採購、星級評分、自訂品質標籤庫、供應商排行榜。
