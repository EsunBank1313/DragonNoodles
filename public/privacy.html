📌 核心承諾：龍城麵線僅將您提供的資訊用於「餐點訂購、出餐確認與會員身分識別」。我們絕不販售您的個人資料，亦絕不將您的個人資訊移作任何與點餐服務無關之用途或廣告行銷。

一、我們收集的個人資料項目與方式

當您造訪與使用本線上點餐系統時，我們可能在獲得您的同意後收集以下資訊：

  • 透過 Google 登入收集之資料：
    • 基本個人資訊：您的 Google 帳號顯示名稱（Name）、個人大頭貼照（Profile Picture）。
    • 聯絡資訊：您的 Google 帳號電子郵件地址（Email Address）。
    • Google 唯一識別碼：用於連結與識別您於本系統的訂餐帳號。
  • 訂餐與交易資料：您的訂單明細、購買餐點項目、金額、客製化備註、訂單時間、取餐方式（外帶自取 / 內用桌號 / 外送）。
  • 顧客選填聯絡電話：用於訂單備餐進度通知、到店取餐通知或外送司機配送聯絡。
  • 系統自動紀錄：存取日誌、IP 位址、裝置瀏覽器類型及作業系統，僅供系統穩定度除錯與資安防護之用。

二、個人資料之使用目的與法律依據

我們收集您的資料僅用於達成以下合法、特定之營運目的：

  1. 身分驗證與顧客服務：透過 Google 快速登入完成身分認證，節省繁瑣註冊流程，確保點餐歷程能精確歸屬至您的帳戶。
  2. 履行訂單與餐點製作：廚房製作餐點、打包標記與依預約時間備料出餐。
  3. 訂單狀態推播與通知：即時向您呈現「已接單、製作中、請至櫃台取餐」等進度狀態。
  4. 電子記帳與退款處理：協助處理退單、退款或發票/收據核對事宜。
  5. 系統安全維護：防止自動化惡意惡作劇下單或阻斷式網路攻擊。

三、Google 使用者資料之有限使用合規宣告 (Limited Use Disclosure)

龍城麵線 對於從 Google API 所存取之使用者資訊之使用與移轉至任何其他應用程式，均嚴格遵守 《Google API 服務使用者資料政策》(Google API Services User Data Policy)，並完全符合「有限使用要求」(Limited Use Requirements)：

  • 我們僅將 Google 使用者資料用於提供或改善本點餐系統對顧客顯而易見的使用者面向功能。
  • 我們絕不將 Google 使用者資料移轉給任何第三方，除非是為了提供點餐服務所必須（如雲端主機資料庫安全儲存），或遵守適用法規之強制要求。
  • 我們絕不將 Google 使用者資料用於向您刊登客製化或重新定向（Retargeting）廣告。
  • 我們絕不允許人類閱讀您的個人資料，除非獲得您的明確同意（例如協助技術排除），或是出於資安防護與法律遵循之必要。
  • 我們絕不將您的 Google 資料用於訓練通用人工智慧（AI）或機器學習（ML）模型。

四、資料保存期限與安全防護

  • 資料儲存安全：本系統所有網路傳輸均採用業界標準 SSL/TLS 256 位元高強度加密協定。資料庫儲存於通過 SOC 2 等級認證之雲端數據中心，配置嚴密的資料庫列層級安全存取政策（Row Level Security, RLS），非授權人員無法存取。
  • 保存期限：您的帳號基本資料將保留至您主動申請刪除或帳號終止使用為止；過往交易訂單明細依據商業會計法規與稅務稽核要求，自交易完成日起保存至少 1 年至法定年限後自動去識別化或安全銷毀。

五、使用者權利與資料刪除指引 (Data Deletion Instructions)

根據個人資料保護法及相關國際隱私標準，您對您的個人資料享有以下權利：

  • 查詢、請求閱覽或請求製給複製本。
  • 請求補充或更正您的不正確資料。
  • 請求停止收集、處理或利用您的個人資料。
  • 請求刪除個人帳號及所有相關資料（Request for Data Deletion）：
    若您希望刪除您在「龍城麵線」點餐系統中透過 Google 授權產生的所有個人資料，您可以透過以下任一方式辦理：
    1. 隨時寄信至我們的隱私專用服務信箱：twabc@twabc.com，信件主旨註明「【申請刪除個人資料】- 您的姓名或Google信箱」。

    我們將在確認您的身分後，於 7 個工作日內自伺服器中永久刪除您的個人檔案與授權資訊，並以 Email 回覆確認。
